# Dillon Ultimate Winter Client

Windows x64 launcher for Minecraft 1.21.1 and NeoForge 21.1.267.

The initial preview is mod-free. Public downloads will appear under Releases after the signed package is uploaded. Microsoft sign-in and live game launch still require acceptance testing.

Download only published release packages. Extract the ZIP before running the launcher, and keep feed.json beside the executable. Never provide your Microsoft credentials to anyone; sign in through the Prism Launcher account interface.
